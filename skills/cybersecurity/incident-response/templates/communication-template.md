# Incident Communication Templates

## Internal Alert
```
Subject: [SEVERITY] Security Incident - [Brief Description]

Time Detected: [Timestamp]
Affected Systems: [List]
Current Status: [Investigation/Containment/Recovery/Resolved]
Point of Contact: [Name]

Details:
[Brief description of incident and actions taken]
```

## Customer Notification (if needed)
```
Subject: Security Notice - [Date]

We are writing to inform you of a security incident that may affect your account.
We have taken immediate steps to contain and investigate the issue.

What happened: [Description]
What we are doing: [Actions]
What you should do: [Customer actions if any]
```

## Regulatory Notification
```
Subject: Data Breach Notification - [Organization Name]

To: [Regulatory Authority]
Date of Incident: [Date]
Type of Incident: [Type]
Data Potentially Affected: [Categories of personal data]
Number of Data Subjects Affected: [Count]
Measures Taken: [Actions already taken]
Recommended Actions: [Advice for affected parties]
Contact: [DPO / Incident Manager details]
```

## Executive Briefing
```
Subject: Security Incident Briefing - [Incident ID]

Executive Summary:
[One-paragraph summary of incident, impact, and response status]

Business Impact:
[Revenue, reputation, regulatory, or operational impact]

Current Status:
[Where we are in the IR process]

Key Decisions Needed:
[Escalation, public disclosure, resource requests]
```

## Resolution Notice
```
Subject: Incident Resolution - [ID]

The security incident has been resolved.
Root cause: [Description]
Actions taken: [List]
Future prevention: [Steps]
```
