🚀 **I'm thrilled to announce the v0.1.0 release of Cybersecurity Superpowers!** 🚀

After months of development, I'm open-sourcing a curated set of cybersecurity agent skills designed to supercharge your security workflows. Whether you're a DevSecOps engineer, a security analyst, or a developer building secure software, this toolkit has something for you.

**What's included:**

🔒 **Secure-Coding Skill** — Language-specific security checklists (Python, JS/TS, C/C++) with automated scanning to catch vulnerabilities before they reach production.

🔍 **Static-Analysis Skill** — Flexible source code analysis supporting SARIF, JSON, and plain text output with configurable severity thresholds.

🚨 **Incident-Response Skill** — Pre-built playbooks and runbooks for phishing, data breaches, ransomware, and DDoS incidents. Turn chaos into a structured response.

📋 **Compliance-Audit Skill** — Framework-aligned checklists for SOC 2, ISO 27001, PCI DSS, HIPAA, and GDPR. Accelerate your audit readiness.

🌐 **Threat-Intelligence Skill** — STIX/TAXII feed integration with IOC extraction and MITRE ATT&CK mapping.

**The orchestrator** ties it all together — run a single pipeline that chains all five skills and produces a consolidated security report.

This project integrates seamlessly with OpenCode and Claude Code, making it dead simple to bring cybersecurity expertise into your AI-assisted development workflow.

The entire codebase is open source, built with shell scripts and markdown for maximum portability and transparency. No proprietary tools. No lock-in.

Check it out, star the repo, and feel free to contribute! Good first issues are tagged and ready for new contributors.
