🚀 **I'm thrilled to announce the v0.1.0 release of Cybersecurity Superpowers!** 🚀

After months of development, I'm open-sourcing a curated set of cybersecurity agent skills designed to supercharge your security workflows. Whether you're a DevSecOps engineer, a security analyst, or a developer building secure software, this toolkit has something for you.

**What's included:**

🔒 **Threat-Modeling Skill** — STRIDE-based threat analysis with CVSS v3.1 scoring, MITRE ATT&CK mapping, and OWASP/NIST mitigation recommendations.

🔍 **Secure-Coding Skill** — Language-specific OWASP security checklists (JavaScript, TypeScript, Python, Go, Rust) with automated scanning to catch vulnerabilities before they reach production.

📋 **Static-Analysis Skill** — Source code analysis supporting SARIF, JSON, and markdown output. Integrates with semgrep, bandit, gosec, and npm audit with dry-run mock data support.

🚨 **Penetration-Testing Skill** — Scoped red-team plans mapped to MITRE ATT&CK tactics and OWASP WSTG test cases.

📝 **Incident-Response Skill** — Pre-built NIST SP 800-61 aligned playbooks for ransomware, data breaches, phishing, DDoS, and insider threats.

🔗 **Supply-Chain Security Skill** — SBOM generation in CycloneDX and SPDX formats with dependency vulnerability cross-referencing.

**The orchestrator** ties it all together — run a single pipeline that chains all skills and produces consolidated security reports. Pre-commit and pre-push hooks enforce security gates automatically.

This project integrates seamlessly with OpenCode and Claude Code, making it dead simple to bring cybersecurity expertise into your AI-assisted development workflow.

The entire codebase is open source, built with shell scripts and markdown for maximum portability and transparency. No proprietary tools. No lock-in.

Check it out, star the repo, and feel free to contribute! Good first issues are tagged and ready for new contributors.
